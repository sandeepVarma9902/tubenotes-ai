Quick Guide

In one line

A visual tour of how neural networks learn: forward pass, loss, backpropagation and gradient descent.

Key takeaways

  • A neuron is just a weighted sum plus a non-linearity
  • Loss measures "how wrong" the network is — everything optimises this one number
  • Backprop is the chain rule applied layer by layer, backwards
  • Gradient descent = small steps downhill on the loss landscape
  • Learning rate is the step size — too big diverges, too small crawls

Handbook

Handbook

Overview

Training a neural network means finding weights that minimise a loss function. Three ideas do all the work: the forward pass computes predictions, the loss scores them, and backpropagation tells every weight how to change.

Core concepts

  • Forward pass — input flows through layers to produce a prediction
  • Loss function — a single number measuring error, e.g. mean squared error
  • Backpropagation — chain rule distributing blame backwards through layers

Step-by-step walkthrough

  • Initialise weights randomly (small values)
  • Forward pass → compute loss on a batch
  • Backpropagate gradients to every weight
  • Update: w -= learning_rate × gradient
  • Repeat until the loss plateaus

Cheat sheet

Too high LR → loss explodes · too low LR → trains forever · start at 1e-3 with Adam and tune from there.
